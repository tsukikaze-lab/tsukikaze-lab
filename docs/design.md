# tsukikaze lab サイト設計書 v0.1

## 1. 目的
- 「月風まい / tsukikaze lab」の活動拠点。作ったもの（Works）と開発記録（Log）を一か所に集める
- 今後のツール・ゲーム・YouTube への入口にする
- 自分自身の Web 開発の練習台（設計 → 実装 → 公開 → 計測 → 改善を一周する）

## 2. 想定読者
- 個人開発・AI 活用に興味がある人（X / Zenn から流入）
- 作ったツールを使いに来た人
- 将来：ゲームや動画から来た人

## 3. ページ構成（初期リリース）
| パス | 内容 |
|---|---|
| `/` | トップ。短い紹介文（1〜2行）＋最新 Works ＋最新 Log |
| `/works` | 作品一覧（カード表示）。最初は「このサイト自体」を Work #1 として掲載 |
| `/works/[slug]` | 作品詳細（概要・使った技術・リンク） |
| `/log` | 開発記録の一覧 |
| `/log/[slug]` | 記事ページ（Markdown で書く） |

- 共通ヘッダー：ロゴ（tsukikaze lab）／Works／Log
- 共通フッター：月風まい／X／GitHub へのリンク
- About ページは初期リリースでは作らない。プロフィールはトップとフッターに簡潔に置き、後で追加する

## 4. デザイン
### 雰囲気
静かな夜・和モダン。余白多め、装飾は控えめ、月と風をさりげなく感じさせる。

### 配色（伝統色ベース・ライト/ダーク自動切替）
| 役割 | ライト（昼・月白） | ダーク（夜・夜空） |
|---|---|---|
| 背景 | 月白 `#EAF4FC` | 夜空 `#0B1426` |
| 面（カード等） | `#FFFFFF` | `#14213A` |
| 本文 | 濃藍 `#0F2350` | 月白 `#EAF4FC` |
| 補助テキスト | `#4A5B78` | `#9FB3CC` |
| アクセント | 藍色 `#165E83` | 空色 `#A0D8EF` |
| 境界線 | `#C9DCEC` | `#24344F` |

- 閲覧者の OS 設定（prefers-color-scheme）に合わせて自動で切り替える
- 文字と背景のコントラストは WCAG AA 以上を確保する

### フォント（Google Fonts）
- 見出し：Zen Old Mincho（和の雰囲気）
- 本文：Noto Sans JP（読みやすさ優先）

### ロゴ・アイコン
- 初期はテキストロゴ「tsukikaze lab」
- ファビコンは月のシンプルな図形。手描きロゴは後で差し替え

## 5. 技術構成
| 項目 | 選定 |
|---|---|
| フレームワーク | Astro（静的サイト生成） |
| コンテンツ | Markdown（Astro Content Collections で Works / Log を管理） |
| ソース管理 | GitHub（`tsukikaze-lab` アカウント） |
| 公開先 | Cloudflare Pages（GitHub に push すると自動公開） |
| URL | 初期は `*.pages.dev` の無料 URL。独自ドメインは後から |
| 計測 | Cloudflare Web Analytics（無料・Cookie 不要） |
| 言語 | 日本語のみ |

## 6. 品質要件
- スマホ表示に対応（幅 375px でも崩れない）
- OGP 設定（X で共有したときにカードが出る）
- sitemap.xml と Log の RSS フィード
- ページは軽く保つ（画像は最小限）

## 7. 進め方
1. 環境準備：Node.js / Git の導入、GitHub アカウント作成
2. Astro の雛形を作成し、ローカルで表示する
3. 配色・フォント・共通レイアウトを実装する
4. 初期コンテンツ：Works #1「このサイト」、Log #1「始めます」
5. GitHub に上げて Cloudflare Pages で公開する
6. Web Analytics を設定し、X で告知して反応を見る
